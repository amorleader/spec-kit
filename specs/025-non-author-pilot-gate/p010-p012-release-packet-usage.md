# P010-P012 Release Packet Usage

Use this sequence after the pilot session to close decision phase quickly.

## Step 1: Finalize Report (`P010`)

- Open: `p010-report-completion-checklist.md`
- Fill: `non-author-pilot-report.md`

## Step 2: Publish Decision (`P011`)

- Open: `p011-rollout-decision-onepager.md`
- Copy core rationale from report and set final GO status.

## Step 3: Publish Backlog Snapshot (`P012`)

- Open: `p012-next-phase-backlog-snapshot.md`
- Add unresolved actions and assign owners/dates.

## Output Bundle

- `non-author-pilot-report.md`
- `p011-rollout-decision-onepager.md`
- `p012-next-phase-backlog-snapshot.md`

## Close Criteria

- Decision is documented.
- Conditions and risks are explicit.
- Next-phase backlog has owner and due date per P0/P1 item.
