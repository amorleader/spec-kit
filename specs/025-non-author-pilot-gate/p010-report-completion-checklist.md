# P010 Report Completion Checklist

Use this checklist to finalize `non-author-pilot-report.md` in 10-15 minutes.

## Input Sources

- `specs/025-non-author-pilot-gate/non-author-run-log-session-01.md`
- `specs/025-non-author-pilot-gate/p005-p006-fast-close-template.md`
- `specs/025-non-author-pilot-gate/p007-severity-rootcause-rules.md`
- `specs/025-non-author-pilot-gate/p008-remediation-mapping-template.md`

## Fill Order

1. Fill `Acceptance Criteria Check` (AC1-AC4).
2. Fill `Quantitative Summary` from `Post-Session Extraction`.
3. Fill `MHR Contract Check Summary` from endpoint checklist.
4. Write top 3 `Key Findings` from blocker/intervention table.
5. Populate `Remediation Actions` from P008 mapping table.
6. Draft `Rollout Recommendation` with explicit rationale.

## Quality Gate

- All four AC items have PASS/FAIL value.
- All quantitative fields have numeric or explicit `N/A`.
- MHR endpoint results are explicit (status + observation).
- At least one P0/P1 action exists if any High/Critical issue was found.
- Recommendation includes remaining risks and next checkpoint criteria.

## Completion Marker

- `P010` can be marked done only when all quality-gate items pass.
